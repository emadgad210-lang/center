# سبّورة | لوحة تحكم السنتر التعليمي 🎓

نظام متكامل لإدارة السنتر التعليمي مع تصميم عصري وسهل الاستخدام.

## 🆕 الميزات المُضافة حديثاً

### 📋 نظام النسخ الاحتياطية (Backup System)

#### ✨ المميزات:
- **📤 تصدير البيانات**: احفظ جميع بيانات السنتر في ملف JSON آمن
- **📥 استيراد البيانات**: استعيد البيانات من نسخة محفوظة سابقة
- **📊 سجل النسخ**: عرض آخر 10 نسخ احتياطية مع التفاصيل
- **🔒 آمن تماماً**: لا توجد بيانات حساسة في الملف

#### 🚀 كيفية الاستخدام:

**1. الوصول للميزة:**
```
تسجيل الدخول كـ أدمن → القائمة الجانبية → "النسخ الاحتياطية" ✓
```

**2. تصدير البيانات:**
```
اضغط "📤 تصدير الآن" → أكد → ملف JSON يُحفظ تلقائياً ✓
```

**3. استيراد البيانات:**
```
اضغط "📥 استيراد من ملف" → اختر الملف → أكد التحذير ✓
```

#### ⚠️ تنبيهات مهمة:
- **عند الاستيراد**: ستُحذف جميع البيانات الحالية
- **تأكيد مزدوج**: يُطلب منك تأكيد قبل الاستيراد
- **الملف الآمن**: يحتوي على جميع البيانات - احفظه بحذر
- **السجل محلي**: يُحفظ على الجهاز فقط (localStorage)

## 💾 التخزين والبيانات

### حيث تُحفظ البيانات؟
- **التخزين المحلي**: `localStorage` في المتصفح
- **آمن**: لا تُرسل البيانات لأي سيرفر
- **خصوصي**: كل جهاز يحفظ بيانات منفصلة

### نسخ احتياطية:
- **محلية**: في `localStorage` على الجهاز
- **يدوية**: عبر تصدير ملفات JSON
- **دورية**: يمكنك جدولة النسخ الاحتياطية

### حذف البيانات:
- **تنظيف المتصفح**: سيحذف البيانات
- **استخدام Incognito**: لا يحفظ البيانات
- **إعادة تعيين**: افتح الأدوات والقيّد cache

## 🆕 الميزات الجديدة بالتفصيل

### نظام النسخ الاحتياطية

#### التصدير (Export):
```javascript
✓ ينقر الأدمن "تصدير الآن"
✓ يُحفظ ملف JSON بكل البيانات
✓ الملف يُسمى: sabbora-backup-[التاريخ].json
✓ يتضمن: students, teachers, classes, ...
✓ يُضاف للسجل تلقائياً
```

#### الاستيراد (Import):
```javascript
✓ ينقر الأدمن "استيراد من ملف"
✓ يختار ملف JSON من جهازه
✓ تحذير: البيانات الحالية ستُحذف
✓ يأكد العملية
✓ تُستعاد جميع البيانات
✓ يُضاف للسجل تلقائياً
```

#### السجل (History):
```javascript
✓ عرض آخر 10 نسخ احتياطية
✓ لكل نسخة: الاسم، التاريخ، الحجم، النوع
✓ إمكانية حذف من السجل
✓ يُحفظ محلياً على الجهاز
```

## 🔒 الأمان والخصوصية

### ✅ آمن:
- ✓ لا يُرسل بيانات خارج الجهاز
- ✓ لا يتطلب نت للعمل (offline)
- ✓ كلمات المرور مشفرة محلياً
- ✓ لا توجد إعلانات أو تتبع

### ⚠️ انتبه:
- ⚠️ البيانات تُحفظ محلياً فقط
- ⚠️ حذف المتصفح = حذف البيانات
- ⚠️ الملف المصدَّر يحتوي على كل شيء
- ⚠️ لا توجد استعادة من الحذف النهائي

## 📞 الدعم والمساعدة

### الأسئلة الشائعة:

**س: كيف أعمل backup تلقائي؟**
ج: استخدم ميزة التصدير كل أسبوع

**س: ماذا إذا ضاع الملف المصدَّر؟**
ج: البيانات محفوظة محلياً، عمّل export جديد

**س: هل يمكن تعديل ملف النسخة؟**

ج: لا يوجد حد، لكن قد يبطئ المتصفح

**س: هل آمن على البيانات الشخصية؟**
ج: نعم، البيانات محلية تماماً
